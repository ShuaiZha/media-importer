# 飞书配置

[文档目录](README.md) · [配置参考](configuration.md) · [日常使用](operations.md)

使用**企业自建应用机器人 + 长连接 + 本人单聊**，无需群 Webhook 或公网回调地址。同一应用只运行一个实例。

## 1. 准备应用与凭据

1. 在[开发者后台](https://open.feishu.cn/app)创建企业自建应用，添加「机器人」能力。组织需允许创建与发布应用。
2. 从「凭证与基础信息」取得 App ID、App Secret。
3. 在「权限管理」开通以下**应用身份权限**：

| 权限 | 用途 |
| --- | --- |
| `im:message:send_as_bot` | 发送消息、更新自己的卡片 |
| `im:message.p2p_msg:readonly` | 接收本人单聊消息 |

取得本人 Open ID：在 [API 调试台](https://open.feishu.cn/api-explorer)选中此应用，打开「发送消息」接口 `POST /open-apis/im/v1/messages`，将 `receive_id_type` 设为 `open_id`，点击「快速复制 open_id」选择自己。只需复制，无需发送消息。

三个值填入安装向导或本机 `.env`：

```dotenv
FEISHU_APP_ID='cli_EXAMPLE00000000'
FEISHU_APP_SECRET='REPLACE_WITH_APP_SECRET'
FEISHU_OWNER_OPEN_ID='ou_EXAMPLE00000000'
```

不要使用其他应用的 Open ID、组织 `user_id` 或群 `chat_id`。程序只接受配置的本人操作。

## 2. 启动本机服务

安装 [原生 CLI](native.md) 或 [Docker Compose](deployment.md)，保持后台在线：

| 检查 | 原生 | Docker |
| --- | --- | --- |
| 后台健康 | `media-importer status` | `docker compose ps` |
| 连接日志 | `media-importer logs` | `docker compose logs --tail 100 bot` |

程序已包含飞书官方 SDK，无需另跑示例程序。后台确认建立长连接后，才能保存下一步订阅。[官方长连接说明](https://open.feishu.cn/document/server-docs/event-subscription-guide/event-subscription-configure-/request-url-configuration-case)

## 3. 订阅与菜单

在「事件与回调」中分别保存：

| 页签 | 接收方式 | 订阅 |
| --- | --- | --- |
| 事件配置 | 长连接 | `im.message.receive_v1`、`application.bot.menu_v6` |
| 回调配置 | 长连接 | `card.action.trigger` |

文字、菜单事件和卡片回调分别接收命令、打开入口与处理确认。不填写请求 URL、Verification Token 或 Encrypt Key。

在「机器人 → 机器人自定义菜单」启用可切换菜单、默认展示菜单。每个子项选择**推送事件**，填写下表标识。

下表对应 **v0.11.2**；先更新程序，再发布菜单。旧版 v0.11.0 的替代事件见表下注释。

| 主菜单 | 子菜单 | 事件标识 |
| --- | --- | --- |
| 同步 | 同步状态 | `sync.status` |
| 同步 | 开启同步 | `sync.start` |
| 同步 | 停止同步 | `sync.stop` |
| 同步 | 选择文件 | `sync.select` |
| 相机 | 相机状态 | `camera.overview` |
| 相机 | 连接相机 | `camera.connect` |
| 相机 | 相机页面 | `camera.workspace` |
| 相机 | 清理原片 | `camera.cleanup` |
| 设置 | 素材与清理 | `settings.media` |
| 设置 | 传输与缓存 | `settings.transfer` |
| 设置 | 相机与预览 | `settings.camera` |
| 设置 | 归档存储 | `settings.destination` |
| 设置 | 消息通知 | `settings.notifications` |

v0.11.0 使用 `camera.capture`、`sync.cleanup`、`settings.source` 分别替代相机页面、清理原片、相机与预览的事件；`camera.connect` 需要 v0.11.2。v0.10.26 及之前使用“发送文字消息”，不能使用事件菜单。新版继续接受旧事件和文字别名；旧“拍摄控制／实时预览”入口转到相机页面，不启动预览。

**更新本机程序不会更新飞书后台菜单。** 菜单、订阅修改后须发布应用版本。无需新增权限或更换凭据。[官方菜单说明](https://open.feishu.cn/document/client-docs/bot-v3/bot-customized-menu)

## 4. 发布与验证

在「版本管理与发布」创建版本，将可用范围限定为本人并发布；组织要求审核时由管理员批准。保存草稿不等于发布，权限、订阅和菜单变更后也要发布。

菜单发布后若客户端仍显示旧名称，重新打开飞书客户端；无需重新创建应用或更换凭据。

打开机器人单聊，保持原片删除关闭：

1. 「同步 → 同步状态」返回简短快照；「查看详情」显示文件、速度、空间和实际路径，「刷新」更新原卡。
2. 连接相机，核对身份后点击「确认相机」。确认只授权设备，不开启同步；同步已经开启时继续原流程。
3. 「相机 → 相机状态」显示连接、拍摄状态、电量和剩余空间；「设备详情」查看序列号、固件和素材统计。
4. 「相机 → 相机页面」仅返回入口，不自动预览或录像。
5. 先停止全量同步，再用「同步 → 选择文件」导入一个小文件，核对进度、归档结果和缓存清理。本次选择导入固定保留原片。
6. 「相机 → 清理原片」预览并取消，确认取消前后原片不变。
7. 设置保存回执区分「等待生效」和「已生效」；关闭自动通知不影响主动查询和操作回执。

**开启同步会处理当前类别范围内的全部待导入素材及完整缓存。** 首次验收应使用少量素材。相对 v0.11.0，v0.11.2 确认相机只授权设备，不再自动开启同步。

「相机 → 连接相机」仅建立连接，不改变同步、预览或录像状态。已连接时返回当前设备；仅 USB 模式提示插线；自动或无线模式复用后台连接流程，最长尝试 150 秒。重复点击复用当前请求，结果更新原卡。新相机仍需确认。开启同步本身已包含自动连接，无需先点此菜单。

## 参数设置

| 设置卡片 | 内容 |
| --- | --- |
| 素材与清理 | 素材范围、预览文件、原片删除确认 |
| 传输与缓存 | 上传限速、缓存额度、磁盘预留；运行间隔在高级项 |
| 消息通知 | 自动通知、进度间隔；连接提醒与通知前缀在高级项 |
| 归档存储 | SMB 地址、端口、共享名、子目录、显示名称、账号、认证域、新密码 |
| 相机与预览 | 相机连接策略与请求参数；本机 / Tailscale 观看入口及连接检查 |
| 本机目录（文字命令） | 查看实际配置、任务与缓存路径，以及迁移说明 |

v0.11.0 的业务配置统一保存在 JSON；`.env` 仅保留本机部署和飞书首次连接凭据。表单显示当前值，保存时校验并原子写入 JSON。每张表单独立校验并原子保存；高级项不会覆盖主表单的值。过期卡片不能覆盖较新的设置，控制回执在后台应用后更新。限速与缓存限制在当前文件结束后应用；降低额度不会清空缓存。

「同步 → 停止同步」中断两路当前传输；运行中卡片的「停止同步 → 当前文件完成后停止」让两路完成各自当前文件后停止，不开始新文件。两者均保留未归档的完整缓存，回执在后台实际停止后更新为「同步已停止」。

## 选择素材导入

1. 停止全量同步，连接并确认相机。
2. 从「同步 → 选择文件」读取清单，在下拉框中分页多选；每个 MP4 只显示自己的文件名和大小，正文不重复列清单。翻页时保存本页选择。
3. 点击「保存并预览」，核对实际归档文件、数量和总大小；超过 12 个时可查看完整清单。确认后开始，两路进度与结果更新在原卡片。

每个主文件与它直接关联的 LRV、THM 沿用当前预览文件归档设置；其他 MP4 不会联动勾选。无法确认关联的文件单独展示。新增或身份变化的素材不会擅自加入本次任务；已有正式归档核验通过后跳过。升级前已经确认的任务保持原有范围。

本次任务**固定保留相机原片**，不修改全量同步或自动删除开关。未选任务与缓存不处理；完成后清理本次归档缓存和任务明细。需要清理原片时，另用下方的预览确认入口。

SMB 离线时继续导入，断开相机后继续上传完整缓存。卡片可停止和继续本次任务；「立即停止」「当前文件完成后停止」也适用。中断的文件重新传输，完整缓存保留。修改配置会暂停任务，核对后可继续原范围；切换到其他目的地时不能接管旧任务。

## 拍摄控制

Mac 原生无线模式从「相机 → 相机页面」进入。打开入口只查询状态；连接、预览、拍摄和参数修改需要明确点击。

- 录像、拍照、延时摄影、HiLight、模式及参数均在页面内操作。可用参数以相机返回的能力为准，修改后读回核验。
- 运行中的卡片保留「停止录像」或「结束预览」，两者与「停止同步」互不替代。
- 定长录像由相机计时，断开电脑后仍按设置结束；「不限时」须手动停止。
- 拍摄完成且识别到新素材时，卡片出现「导入本次素材」；确认后只处理本次范围，固定保留原片。
- 操作超时先核验实际状态，不自动重发拍摄指令。连接变化后重新查询。

相机接入 USB 数据模式时不会提供无线拍摄按钮。无线连接要求见[兼容性](compatibility.md#无线连接与拍摄控制)。

### 相机页面

「相机 → 相机页面」返回「打开相机页面」按钮。Mac 原生后台提供页面，沿用预览的本机 / Tailscale 入口。

宽屏将取景与拍摄参数并排展示，窄屏上下排列。播放状态、重新连接和兼容播放位于画面下方，不需要在视频框内滚动。

- **拍摄**：同页查看实时取景、开始 / 停止录像、拍照、HiLight，以及读取和修改当前预设参数。HERO9 拍摄或修改参数前先结束预览；页面按钮会说明并反映实际结果。
- **相机素材**：每个 MP4 独立展示原文件名、大小和缩略图；点击回放，支持拖动进度。优先播放确认关联的 LRV，缺少时尝试原 MP4；原文件编码不被观看端支持时明确提示，不自动转码。照片显示相机提供的缩略图。
- 浏览素材须先结束实时预览。浏览期间暂缓相机导入与清理，完整缓存仍按同步开关上传。离开素材页或关闭窗口后解除占用；网络中断时占用最多约 25 秒后失效。回放片段按需读取，不进入备份缓存，也不创建任务或删除原片。

相机控制入口仅向已授权本人提供，1 小时后失效；请从飞书重新获取。旧「打开画面」仍是只读链接，不能操作相机。关闭页面不会停止录像或实时预览，结束测试后须主动停止。

## 实时预览

需要 v0.11.0 的 **Mac 原生包、HERO9 Black 无线连接**。Mac 使用有线上网，Wi-Fi 连接相机。go2rtc 随程序安装、更新和回收，无需单独运行服务或安装 FFmpeg。

1. 从「相机 → 相机页面」打开页面，点击「开启预览」。尚未连接时后台尝试连接已确认的相机。
2. 画面就绪后直接在页面内播放。配置远程入口后，观看端需登录同一 tailnet 并获准访问，使用 HTTPS/WSS 播放。
3. 观看窗口关闭、锁屏或暂时断网**不会结束相机预览**；同一会话可重新打开，没有 60 秒无人观看限制。
4. 点击页面或卡片的「结束预览」停止取流、回收组件并立即撤销播放链接；服务退出或相机流故障也会结束，不会在重启后自动开启。

预览期间相机导入与原片清理等待，完整缓存按同步开关继续上传。停止同步不会停止预览。拍摄控制的「刷新状态」不打断导入；「停止录像」优先执行。HERO9 从预览转为录像、拍照或延时摄影前先确认预览已停止；拍摄结束后可重新开启预览，结果未知时不重复发送拍摄命令。

远程入口一次配置见[原生部署](native.md#远程预览tailscale)。未配置时仅能在运行程序的 Mac 上观看。播放页优先使用 WebRTC 低延迟模式，失败后自动切换 HLS / MSE 兼容模式；页面显示当前模式，并提供手动切换与重连。客户端页面可达不等于视频可播；Windows、手机飞书的实际播放以[兼容性记录](compatibility.md#实时预览)为准。


## 相机操作

「相机状态」显示型号、连接方式、拍摄状态、电量和存储卡剩余空间；序列号、固件、素材统计放入「设备详情」。缺失或过期数据明确标注，正常温度不常驻显示。

「清理原片」是一次性操作，不改变同步或自动删除开关，同步关闭时也可使用：

| 范围 | 清理条件 |
| --- | --- |
| 已归档素材（默认） | 本程序保存了正式归档记录，SMB 文件大小与身份仍匹配 |
| 已完整导入素材 | 本地完整缓存通过核验，或正式归档仍通过核验；未归档时缓存可能是唯一副本 |

先显示清理范围、文件数和预计释放空间；关联范围及保留原因在文件清单中查看。确认有效期 5 分钟，执行前再次核验；相机连接或配置变化时需重新预览。已确认关联且按设置跳过归档的预览文件随主素材处理，关联不明或新增文件保留。

选择上传与删除核验使用不同范围：MP4 可以单独上传；清理仍须核对设备关联的完整素材，不能仅凭某个 MP4 已归档就删除其他文件。

相机操作等待当前导入文件结束后执行，上传按原设置继续。可从卡片停止本次操作；同步菜单的两种停止方式也会停止新的原片删除。结果区分「已删除」「原片已不存在」「保留」「待核验」；断线导致结果不明时，重新连接后可点击「复查删除结果」，该操作只复查、不继续删除。服务重启不会自动恢复未执行的删除。

手动清理与自动清理共用[机型与固件验证范围](compatibility.md#gopro)，不提供清空存储卡或格式化操作。已有任务明细收尾后，仍可使用保留的去重及归档依据核验原片。

## 修改连接与目录

修改归档位置需先停止同步。程序用小文件检查写入、改名和删除权限，通过后显示确认卡：

- **修改原存储连接**：例如 IP 改域名，必须核验仍为同一归档；任务与去重身份不变。没有可核验依据时拒绝接管。
- **切换到新归档位置**：要求旧任务、完整缓存与清理事项已收尾。已有归档不移动，之后新扫描的素材归档到新位置；相机中保留的素材可能再次归档。

“新密码”留空沿用当前密码。填写后会通过飞书提交，程序只把密码保存到本机 `config/credentials/`，不回显到回复、不写入任务或日志；检查通过并确认后才切换。认证失败保留原配置。账号改变仍须核验是原存储，不能绕过目的地身份保护。

相机连接修改前也需停止同步；地址与序列号只作发现提示，不能替代设备确认。运行间隔在当前文件结束后应用。旧卡片不能覆盖新值，重复提交不重复修改。

首次连接飞书的 App ID、Secret、本人身份由安装向导填写；只有机器人先连上才能接收配置。缓存换盘、系统权限和 Docker 宿主机挂载仍按[迁移说明](recovery.md)在本机操作，不能只改路径。本机目录卡提供实际位置与操作说明。

## 通知

自动通知默认关闭，连接／断开提醒也默认关闭。开启同步立即返回一张进度卡；自动通知开启后，按设定间隔更新原卡。导入完成、归档完成和需要处理的异常单独提醒；导入与归档同时完成时只发送归档完成。

| 消息 | 内容与生命周期 |
| --- | --- |
| 状态 / 进度 | 当前结论、两路进度、连接与阻塞原因；详情按需展开 |
| 导入完成 | 已导入数量、待归档数量；读取结束时明确标注 |
| 归档完成 | 数量、大小、目的地和实际清理结果；清理失败不撤销归档成功 |
| 需要处理的异常 | 影响、原因、一条下一步；同一故障一次提醒，恢复更新原卡 |
| 普通等待 / 短暂断线 | 只更新状态；连续六小时无进展仍提醒 |
| 操作回执 | 同一张卡经历处理中、成功或失败；不受自动通知开关影响 |

事件消息使用飞书自带时间。快照仅显示一次「更新 HH:mm」，跨日补日期、跨年补年份；显示按 UTC+8 换算，数据库时间不变。逐文件日志留在本机。

未知文字仅返回菜单引导。过期卡片不能修改配置；删除原片和切换目的地仍须确认，归档预览文件等普通设置直接保存。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 搜不到机器人 | 机器人能力、发布状态、本人可用范围、客户端组织 |
| 无法保存长连接 | 后台是否运行，App ID/Secret 是否匹配，网络是否可达 |
| 菜单缺失或旧版 | 发布后重新进入会话，先输入 `状态` 验证 |
| 文字无回复 | 消息权限、事件订阅、Owner Open ID、菜单动作 |
| 卡片不能操作 | 卡片回调是否发布；重新获取卡片，旧卡可能已失效 |
| 能查状态但无自动提醒 | `notifications.enabled`、本机发送日志 |

共享日志前移除凭据、私人路径与身份信息。设备或存储问题见[排障表](operations.md#故障排查)。

### 预览入口设置

从「设置 → 相机与预览 → 观看入口」进入；文字 `预览设置` / `预览连接检查` 可直接打开。无需新增权限。

- 「读取本机入口」读取已有 Tailscale HTTPS 映射，填入表单但不保存；也可以手动填写本机 MagicDNS 地址。
- 「检查当前连接」只读检查本机播放服务、Tailscale、映射与 HTTPS，不启动预览、不修改 Serve。
- 「检查并保存」在检查通过且预览已结束后保存；留空表示仅本机。检查失败或配置已被其他操作修改时保留原配置。
- 观看端需要连接 Tailscale 并具备访问权限。本机检查通过不代表已经验证了手机外网播放。

Tailscale 安装、登录、访问策略和 Serve 配置仍在本机管理，操作见[远程预览](native.md#远程预览tailscale)。
