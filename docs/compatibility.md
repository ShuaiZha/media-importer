# 兼容性与运行条件

[文档目录](README.md) · [原生 CLI](native.md) · [Docker Compose](deployment.md)

Media Importer 以「来源设备 → 本地缓存 → 归档目的地」组织流程。当前已实现的适配如下，通用的流程与命名不代表支持任意设备或协议。

| 环节 | 当前适配 | 范围 |
| --- | --- | --- |
| 素材来源 | GoPro，经 USB 网络读取 | 每个实例一次处理一台设备，机型与固件能力见下表 |
| 归档目的地 | SMB | 每个实例一个目的地，可为 NAS、电脑共享或其他 SMB 服务器 |
| 控制与通知 | 飞书自建应用机器人 | 本人单聊、设备确认、同步控制与通知 |

其他相机品牌、无线连接及其他存储协议尚未接入。新增适配需实现设备或协议差异，并单独验证导入、归档和原片清理能力。

## GoPro

GoPro 是当前首个设备适配。兼容性按型号和固件判断，不限制为某一台设备的序列号；现有实机验收使用 HERO9 Black 完成。

| 型号与固件 | 导入与归档 | 原片删除 |
| --- | --- | --- |
| HERO9 Black，`HD9.01.01.72.00` | macOS 上已实测视频、分段视频及附属文件 | MP4 与关联 LRV 已实测；照片、连拍仍待专项验收 |
| HERO9 其他固件；HERO10 / 11 / 12 / 13 Black、HERO11 Black Mini | 使用通用 HTTP 接口，允许确认后导入；待实机验收 | 强制保留原片，即使用户开启删除开关 |
| 其他或无法识别的型号 | 仅显示识别信息，暂不开放导入 | 不开放 |

验证结论来自项目实测，不能用官方接口支持代替。HERO9 的分段组合与部分 MP4 元数据补读是保留的机型差异；设备名称和归档目录采用实际识别结果。

### USB 连接要求

1. 相机开机，使用支持数据传输的 USB 线连接电脑。
2. 系统识别到相机的 USB 网络接口，程序能够访问相机 HTTP 服务。仅充电或 MTP 文件传输不满足条件。
3. 原生程序或 Docker 容器能访问该 USB 网络。Docker 通过网络读取，不使用 USB 设备直通。

本项目不保证“插线自动开机”。电脑需保持唤醒，外接缓存盘保持挂载。

`SOURCE_URL` 和 `SOURCE_SERIAL` 可留空自动发现，也可填写优先探测提示。GoPro USB 地址通常由序列号最后三位 `XYZ` 推导为 `http://172.2X.1YZ.51:8080`；例如 `789` 对应 `http://172.27.189.51:8080`。这是相机地址，不是电脑网卡地址。最终以实际身份读取结果为准。

### 设备确认

新连接会发送型号、序列号、固件和兼容状态，点击「确认并备份」后才读取素材。服务重启、检测到断开或身份变化后需要重新确认；完整缓存仍按同步开关继续上传。

确认与任务归属同时核对来源类型和序列号，不能因不同来源的序列号相同而复用确认或接管任务。

程序依据网络可访问性判断连接：连续至少三次失败且持续不少于 20 秒才认定断开，超过 45 秒没有有效身份观测则暂停相机操作。因此它不会把每次短暂抖动都视为重新插拔。上一台设备仍有未完成传输或清理时，不允许直接切换到另一台。

## 操作系统与安装包

| 平台 | 原生包 / 后台方式 | 实机验证范围 |
| --- | --- | --- |
| macOS Apple Silicon | ARM64 / LaunchAgent | 安装、更新、卸载、飞书及 HERO9 → 本地缓存 → SMB；原生与 Docker 均已验证 |
| macOS Intel | AMD64 / LaunchAgent | 打包与隔离安装测试通过；实际设备链路待验证 |
| Linux | AMD64、ARM64 / `systemd --user` | 打包与隔离安装测试通过；实际后台与 USB 链路待验证 |
| Windows x64 | AMD64 / 用户登录计划任务 | 打包与隔离安装、更新、卸载测试；覆盖文件占用恢复；实际后台与 USB 链路待验证 |

Docker 镜像提供 Linux ARM64 / AMD64。架构可构建、安装测试通过，不代表对应系统的 USB 驱动、相机或 SMB 链路已通过实机验收。Windows ARM 原生包暂不提供。

Windows 卸载的重试机制及 v0.10.21 安装包限制见[卸载说明](native.md#卸载)。隔离测试主动制造文件占用，检查延迟释放、超时报错及再次清理，不涉及相机或真实素材。

原生服务在**用户登录后**启动，不是登录前的系统服务，也不会唤醒休眠电脑。Linux 无 systemd 用户会话时可前台运行 `media-importer run`，或使用 Docker。macOS 原生包尚未进行 Developer ID 公证；开发构建方式见[贡献指南](../CONTRIBUTING.md)。

## 存储与网络

- SMB 共享和目标子目录需提前存在；账号需要列目录、读写、创建、改名和删除临时文件的权限。
- 目的地可使用 IP 或域名。异地 SMB 可经宿主机 VPN / Tailscale 访问，但仍需检查实际运行环境的连通性。
- 缓存可放在本机或外接 SSD；容量不足或原磁盘不可访问时等待，不改用其他磁盘。
- 飞书应用使用主动长连接，无需公网回调地址或映射端口；需要持续访问飞书服务。

首次在待验证组合上使用时，保留原片并使用小素材测试。菜单不提供单文件选择：开启同步会处理配置范围内的全部待导入素材及已有完整缓存。
