# 使用与排障

[文档目录](README.md) · [配置参考](configuration.md) · [迁移与恢复](recovery.md)

## 日常操作

下文菜单适用于 v0.11.2；旧版升级后需更新菜单事件与订阅，见[飞书指南](feishu.md#3-订阅与菜单)。

1. 保持电脑唤醒、缓存盘可用。使用 USB，或按[无线要求](compatibility.md#无线连接与拍摄控制)连接相机。
2. 首次使用在飞书确认卡核对身份，点击「确认相机」，再「开启同步」。之后从「同步 → 开启同步」启动，允许相机暂时离线；程序会按已保存的连接策略自动连接和备份。
3. 从底部「同步 → 同步状态」查看进度；需要停止时从「同步 → 停止同步」停止；需要完成当前文件后再停止，可在运行卡片的停止选项中选择。

同步开启时继续检测新素材。同一已确认设备在重启、重连及 USB / Wi-Fi 切换后核对完整身份并继续；其他设备需要重新确认。旧连接的控制卡失效，不能操作新会话。相机连接要求以状态卡为准；导入结束后，电脑和缓存盘仍需保持可用，直到归档与清理结束。

同步状态与进度卡展示当前结论、两路进度和三端状态；文件、速度、容量和完整归档路径在详情中查看。短暂断连、普通等待只更新原卡；导入完成、归档完成及需要人工处理的异常单独提醒。同一故障不重复提醒，恢复更新原异常卡。

停止同步会取消正在进行的自动无线连接和传输，保留任务与完整缓存。它不会关闭相机或强制切换已连接的 Wi-Fi；无线连接仍需满足[平台与网络条件](compatibility.md#无线连接与拍摄控制)。

| 底部菜单入口 | 行为 |
| --- | --- |
| 同步 → 同步状态 | 两路进度、问题与实际归档位置 |
| 相机 → 相机页面 | 返回页面入口；进入后可预览、拍摄及修改参数 |
| 相机 → 相机状态 | 连接、拍摄状态、电量和卡剩余空间；设备信息与素材统计见详情 |
| 相机 → 连接相机 | 仅建立连接，不开启同步或拍摄；结果更新原卡 |
| 同步 → 开启同步 | 继续任务；来源尚未确认时先要求确认 |
| 同步 → 停止同步 | 中断两路传输和新的原片删除，保留任务与完整缓存 |
| 同步 → 选择文件 | 每个 MP4 独立多选，预览确认后仅导入并归档选中素材，保留原片 |
| 相机 → 清理原片 | 默认预览已归档素材，也可选择已完整导入；确认后执行一次清理 |
| 设置 → 素材与清理 | 素材范围、预览归档和原片处理；开启删除需确认 |
| 设置 → 传输与缓存 | 限速、缓存额度、磁盘预留和运行间隔 |
| 设置 → 消息通知 | 自动提醒、连接提醒、进度间隔 |
| 设置 → 相机与预览 / 归档存储 | 来源提示、SMB 连接与凭据；修改前停止同步 |

合并设置表单需要 v0.10.25+；相机状态、选择素材和手动清理需要 [v0.10.26](releases/v0.10.26.md)。自动无线连接、拍摄控制和实时预览需要 [v0.11.0](releases/v0.11.0.md)。后台菜单需单独[配置并发布](feishu.md#3-订阅与菜单)。飞书设置写入本机 JSON，SMB 密码独立保存；首次飞书凭据和缓存目录迁移在本机处理，见[配置参考](configuration.md)。

## 进度与完成

导入和上传各一次处理一个文件。**A 完整导入即可上传，B、C 继续导入，无需等整批完成。**

| 状态 | 含义 |
| --- | --- |
| 尚未扫描 / 扫描中 | 文件总数尚未确定，不表示完成 |
| 本地导入完成 | 本轮应导入文件已完整缓存或归档，并通过清单复查；原片清理可能仍待处理 |
| 上传字节 100% | 内容已写入临时文件，仍需校验、正式改名与记录 |
| 归档完成 | 正式文件已核验并记录 |
| 已归档 / 缓存待清理 | 归档成功，缓存清理待恢复；不会因此重新上传 |

数量按实际文件统计，失败文件不计完成，跳过的关联预览文件单独说明。整轮归档和必要清理结束后自动清除任务明细，仅保留去重信息和待发送结果；没有历史查询或累计统计。长期结果可保留飞书完成通知。

## 传输与清理规则

### 完整性与归档

1. 导入写本地临时文件，同时计算 SHA-256；大小、来源身份核对并落盘后，登记完整缓存。
2. 上传时顺序读取缓存并再次计算 SHA-256，不一致则停止该文件，保留缓存。
3. 上传写唯一 SMB 隐藏临时文件，核对大小和文件身份，再禁止覆盖地改名。
4. 保存归档结果后清理对应缓存。**不完整读回 SMB 视频。**

旧缓存没有导入流校验值时仍可处理。卷标识、大小、修改时间和少量内容抽样用于确认缓存身份，不能替代整文件校验。

归档路径为「目标目录 / 设备名与序列号 / 原文件名」。重名不区分大小写，依次加 `_1`、`_2`；分配后的路径持久化。正式改名响应丢失时根据发布依据恢复，不能仅凭同名同大小认领文件。去重依据为素材身份与本机记录。

### 原片删除

默认保留原片。开启后，整组应保护的素材完整导入并持久化即可清理相机，**不等待远端归档**；期间缓存可能是唯一副本。

删除前复核设备、组成员及完整副本，删除期间保护组内缓存。跳过归档的关联预览文件，仅在所属素材满足保护条件后清理。关联不明、身份变化、结果不确定或机型未通过删除验证时保留并报告。

当前仅已验证型号、固件的 USB 连接允许删除；无线连接保留原片，开启删除开关不会解除此限制。

删除失败不阻塞缓存上传，也不让已归档状态倒退。关闭删除后，旧删除错误不再阻止已归档且缓存已清理的素材收尾；结果尚未确认的删除仍需核实。

需要手动释放相机空间时，使用「相机 → 清理原片」。默认只处理已核验的正式归档，也可选择已完整导入的素材；两种范围都先预览、再确认，不改变自动删除开关。新增、关联变化或缺少完整副本的素材保留，不能按文件名或大小直接删除。详见[相机操作](feishu.md#相机操作)。

### 停止与中断

没有字节断点续传，中断文件下次从头传；完整缓存和已归档文件不重复传输。程序只清理能确认归属的半文件，离线时登记待清理，恢复后继续。同步关闭仍可清理这些临时文件，不清空完整缓存。

已经完整上传、正在确认正式改名结果的文件进入归档恢复，不作为半文件删除。

### 拍摄优先

Mac 原生无线模式可从「相机 → 相机页面」拍摄。控制请求先停止当前未完成导入，只清理该临时文件；完整缓存继续上传。录像期间等待，停止录像并确认相机就绪后重新扫描并导入。停止同步不等于停止录像。

回执以重新读取的相机状态为准。命令超时或进程中断后只查询结果，不自动重发快门；卡片会明确标出待核验。

Mac 原生版从「相机 → 相机页面」按需观看 HERO9 无线画面。预览组件随程序管理，点击「结束预览」后停止；关闭播放窗口不自动结束。预览期间暂停相机导入与清理，已有完整缓存按同步设置继续上传。通过 Tailscale 可使用同一 HTTPS 入口观看，见[使用说明](feishu.md#实时预览)。

### 仅处理选定素材

使用「同步 → 选择文件」启动一次性任务：先停止全量同步，按文件勾选并预览确认；每个 MP4 可独立上传。未选任务和缓存保留，本次固定保留原片；停止后可从原卡片继续，不会扩展到其他素材。进度和结果更新在同一卡片，详见[选择素材导入](feishu.md#选择素材导入)。

## 自动恢复与等待

| 情况 | 导入 | 上传 |
| --- | --- | --- |
| SMB 离线 | 缓存额度内继续 | 等待恢复 |
| 相机断开、忙碌、录像或过热 | 等待来源可用 | 继续完整缓存 |
| 缓存额度或磁盘预留不足 | 等待空间 | 继续上传释放空间 |
| 缓存盘不可访问 | 等待原盘 | 等待原盘，不切换替代目录 |
| 单个文件失败 | 单独退避重试，其他可处理文件继续 | 同左 |

传输持续无活动时取消本次尝试并重连；无法退出的工作进程由原生监督进程或 Compose 恢复。正常等待和限速不直接视为失活。

### 目的地身份

一份任务绑定一个逻辑目的地。更换域名、IP、端口或账号后，程序读取已有归档的大小与 SMB 身份，确认仍是同一存储后继续。无法确认则保留任务与缓存，提示核对；有待确认发布时先恢复原连接。

切换到另一套存储或新的目录时，使用飞书「设置 → 归档存储 → 切换到新归档位置」，先停止同步并完成旧任务与缓存收尾。新位置使用独立的去重身份，已有归档不移动。旧任务未完成时不要手工改数据库接管。

## 故障排查

先检查后台与日志：[原生命令](native.md#常用命令) / [Docker 命令](deployment.md#管理服务)。停止后台会使机器人离线，停止同步不会。

| 现象 | 下一步 |
| --- | --- |
| 相机仅充电或不可访问 | 检查数据线、开机状态、USB 网络接口，见[连接要求](compatibility.md#usb-连接要求) |
| 发现相机但不导入 | 检查设备确认、同步开关、忙碌与录像状态 |
| 缓存空间不足 | 区分额度与磁盘预留；恢复上传或调整限制，保留未归档缓存 |
| macOS 等待磁盘 / Docker 挂载失败 | 确认原盘、目录和访问权限 |
| 宿主机可连，容器不可连 | 在容器运行 `check --json`，核对 DNS、VPN 路由与防火墙 |
| SMB 间歇失败或不能归档 | 区分 DNS、网络、认证、权限和容量；账号需能创建、改名及删除临时文件 |
| 完整缓存待核验或校验不一致 | 保留文件、`.receipts/` 和快照，按[恢复指南](recovery.md#完整缓存恢复)处理，不删除唯一副本 |
| 飞书无回复或无通知 | 检查身份、发布、订阅和通知开关，见[飞书排障](feishu.md#常见问题) |
| 更新失败 | 保留错误与维护快照，不用旧数据库直接覆盖新任务 |

提交 [Issue](https://github.com/ShuaiZha/media-importer/issues) 时提供版本、系统架构、部署方式、型号与固件、脱敏日志及复现步骤。
