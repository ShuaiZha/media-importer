# 使用文档

[项目首页](../README.md)

## 从这里开始

1. [确认兼容性](compatibility.md)：设备、系统和网络要求。
2. [准备飞书凭据](feishu.md#1-准备应用与凭据)。
3. 安装 [原生 CLI](native.md) 或 [Docker Compose](deployment.md)，二选一。
4. [完成飞书订阅与发布](feishu.md#3-订阅与菜单)，确认设备后开启备份。
