# v0.10.21 · 彻底卸载

[版本列表](../README.md#版本说明) · [GitHub Release](https://github.com/ShuaiZha/media-importer/releases/tag/v0.10.21)

## 变化

- 新增 `media-importer uninstall --purge`：列出实际路径，输入 `DELETE` 后清理本实例程序与登记数据。
- 普通卸载继续保留数据；彻底卸载包含未上传缓存，不操作相机原片、SMB 归档及未登记文件。
- 检查目录归属、磁盘和任务占用；Windows 在进程退出后清理程序目录。

## 升级与验证

原生 `media-importer update` 保留配置、任务、去重和完整缓存，不执行卸载。JSON 4 / SQLite 5 不变。操作范围见[该版本指南](https://github.com/ShuaiZha/media-importer/blob/v0.10.21/docs/native.md)。

测试覆盖两种卸载、取消、危险目录、符号链接、占用、中断与重试。五平台通过打包后隔离测试，设备链路仍按实机结果判断。

Windows 偶发占用的延迟重试与恢复入口在 [v0.10.22](v0.10.22.md) 完善。
