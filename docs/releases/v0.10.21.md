## 原生 CLI 彻底卸载

新增 `media-importer uninstall --purge`。命令先列出清理路径，输入 `DELETE` 后删除本机程序、启动项、凭据、配置、任务、缓存、日志和程序维护备份；脚本调用可使用 `--purge --yes`。

- 普通 `uninstall` 继续保留数据，便于重新安装或切回 Docker。
- 彻底卸载会删除尚未上传的缓存，不操作相机原片或 SMB 归档，也不删除安装目录外的源码、手工备份和其他未登记文件。
- 清理前检查目录归属、原磁盘、任务占用和确认后的路径变化；已中断的数据清理可重试。
- Windows 通过已安装的命令入口，在程序退出后完成程序目录清理。

## 更新

已有原生安装执行 `media-importer update`。更新保留连接配置、同步设置、任务、去重信息和完整缓存，不执行卸载或清空数据。配置与数据库格式保持 JSON 4 / SQLite 5。

提供 macOS ARM64 / AMD64、Linux ARM64 / AMD64、Windows AMD64 原生安装包；Docker 镜像同步更新到 `ghcr.io/shuaizha/media-importer:0.10.21`。安装、两种卸载的范围与确认方式见[原生部署说明](https://github.com/ShuaiZha/media-importer/blob/v0.10.21/docs/native.md)。

测试覆盖保留数据卸载、彻底卸载、取消与缺少确认、危险目录和符号链接、任务占用、清理中断及重试。五种平台均对实际打包的命令执行隔离安装、更新和两种卸载测试，不接触真实相机或用户数据；其他系统的相机链路仍需实机验证。

源码与安装包不包含真实凭据、运行配置、数据库、素材缓存或本机备份。
