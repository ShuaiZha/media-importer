# v0.10.24 · 飞书参数配置

[版本列表](../README.md#版本说明) · [GitHub Release](https://github.com/ShuaiZha/media-importer/releases/tag/v0.10.24)

## 变化

- 飞书「设置」分为素材与清理、传输与缓存、消息通知、归档位置四个入口，表单显示当前参数。
- 保存前校验输入与配置版本，保存后区分等待生效和已生效，避免旧卡片覆盖新设置。
- SMB 地址、端口、共享名和目录可通过检查与确认修改；修改原连接需核验存储身份，切换新位置需先停止同步并完成旧任务与缓存收尾。
- 飞书保存的归档连接写入 JSON，优先于 `.env`；账号凭据和缓存目录迁移仍在本机处理。

## 升级与验证

提供 macOS、Linux 的 ARM64 / AMD64 原生包、Windows AMD64 原生包，以及 `ghcr.io/shuaizha/media-importer:0.10.24` 双架构镜像。原生安装使用文档中的一行命令，已有安装运行 `media-importer update`；容器更新运行 `python3 scripts/manage.py update`。

JSON 4 / SQLite 5 保持不变。现有配置不必重写，任务、去重信息、完整缓存和已有归档保留，升级不改变同步与原片删除开关。新安装继续默认关闭同步、删除原片和自动通知。

本机回归测试运行 461 项，456 项通过、5 项 Windows 专用测试跳过。另以两个 256 KiB 小文件验证独立 SMB 目录切换、归档和缓存清理；飞书实测覆盖菜单、非法输入、参数保存与生效回执，以及同步开启时阻止修改归档位置。未切换实际归档位置或删除相机素材。

菜单发布与配置步骤见[飞书指南](../feishu.md)，原生与容器部署使用相同参数规则。
