# v1.0.1 · 原生更新与版本回收

本版完善 Mac、Windows、Linux 的原生安装与更新流程，不改变素材备份、相机控制及副本保护规则。

## 本版内容

- 新版传输与机器人后台通过健康检查后，自动回收已确认归属的旧程序，仅保留当前版与上一健康版本。
- 文件占用、回收中断或部分删除会保存待处理记录，恢复后继续清理；Windows 文件锁与 Linux 运行程序均有平台回归测试。
- 候选程序验证和复制完成后才停止旧后台，复制失败不中断现有服务；切换前失败的临时程序自动回收，已选中的版本保留待恢复。
- 旧安装通过完整维护快照确认程序归属；普通状态查询保持只读。配置、凭据、任务、完整缓存、日志和维护快照不参与版本回收。
- Mac 主程序固定签名标识，提供可选 Apple 签名身份；临时构建目录在成功或失败后均自动回收。当前公开包仍为临时签名，系统可能再次要求授权，已有权限记录不会自动清除。

## 安装与升级

原生版使用原安装命令获取最新正式包，已有安装执行：

```sh
media-importer update --version 1.0.1
```

首次从 v1.0.0 升级后，新版后台会自动处理可确认的旧程序。上一版程序用于配合升级前快照恢复，不直接降级已变化的数据库。详见[原生更新](../native.md#更新)。

Docker 用户执行：

```sh
python3 scripts/manage.py update --version 1.0.1
```

Windows 将 `python3` 换为 `py -3`。镜像为 `ghcr.io/shuaizha/media-importer:1.0.1`，提供 Linux AMD64 / ARM64；`stable` 指向本版。原生程序回收不负责清理 Docker 镜像。

本版没有配置或数据库格式迁移，不修改既有开关、任务、完整缓存或 SMB 归档，也不需要重新发布飞书菜单。新安装的备份、自动删除与自动通知仍默认关闭。

提供 macOS ARM64 / AMD64、Linux ARM64 / AMD64、Windows AMD64 原生包。设备支持与实机范围沿用 [v1.0.0](v1.0.0.md)；有声直播继续作为实验功能。
