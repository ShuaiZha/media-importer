# v0.10.25 · 飞书完整参数设置

[版本列表](../README.md#版本说明)

本分支待发布版本；公开安装与在线更新仍以 GitHub 最新正式 Release 为准。

- 飞书可修改 SMB 地址、端口、共享、目录、显示名称、账号、认证域与密码。检查通过并确认后生效；失败保留原配置。
- 密码只保存到本机配置目录，卡片、任务与日志不回显；更新快照和迁移备份包含凭据。
- 增加相机发现提示、超时、尝试次数。扫描、重试和清单复查间隔并入「传输与缓存」，六项参数一次校验、原子保存。
- 底部菜单作为统一入口：状态包含运行状态和本机目录，同步包含三种控制，设置包含五类参数。卡片保留表单、必要确认和结果，减少重复导航；菜单需在飞书后台单独更新发布。
- 修正“当前文件完成后停止”的回执：自动停止产生的配置版本变化不再误报为回执失效，后台实际停止后显示停止结果。
- 本机目录卡显示真实路径和迁移说明；换盘、宿主机挂载和首次飞书连接仍在本机完成。

JSON 4 / SQLite 5 保持不变。既有配置、任务、完整缓存与归档不迁移、不清空，同步和原片删除偏好保持不变。

验证：489 项自动测试中 484 项通过、5 项 Windows 专项在 macOS 跳过；覆盖合并表单的原子保存、旧卡片、菜单指令及停止回执，原生安装与更新隔离测试通过。两个 128 KiB 模拟来源文件已通过真实 SMB 归档、身份核验与缓存清理测试。合并表单已在飞书客户端验证六项输入正常显示，保存后后台确认生效。未删除实机素材。
