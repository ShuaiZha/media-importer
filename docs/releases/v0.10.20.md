# v0.10.20 · 原生 CLI

[版本列表](../README.md#版本说明) · [GitHub Release](https://github.com/ShuaiZha/media-importer/releases/tag/v0.10.20)

## 变化

- 新增原生安装、启停、检查、日志、更新与卸载命令，自带 Python 和依赖。
- macOS、Linux、Windows 使用用户登录后台；与 Docker 共用传输核心与数据。
- 可接管已停止的 Docker 项目，保存一致快照并保留配置、任务与完整缓存。
- 更新保留开关和运行状态，普通卸载保留数据。

## 使用与验证

提供五平台原生包及双架构 Docker 镜像。安装与维护见[该版本原生指南](https://github.com/ShuaiZha/media-importer/blob/v0.10.20/docs/native.md)。

Mac Apple Silicon 完成安装、启停、更新、卸载和小文件 SMB 实测。其他平台通过构建与隔离维护测试，实际相机和后台服务仍待实机验证。
