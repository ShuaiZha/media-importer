## 原生 CLI 与 Docker 共用核心

Mac 可直接安装包含 Python 和依赖的命令行程序，无需 Docker 或额外 GUI App。Docker Compose 部署继续保留。

- `install`、`start`、`stop`、`status`、`check`、`logs`、`update`、`uninstall` 统一管理原生服务。
- 接管现有 Docker 项目时保留 `.env`、设置、未完成任务、去重记录和完整缓存，先保存配置与 SQLite 快照。
- 卸载默认保留数据；更新保留开关和运行状态。同一份任务、缓存只运行一种部署。
- Mac 使用 LaunchAgent，Linux 使用用户级 systemd，Windows 使用当前用户登录任务。日常操作继续通过飞书完成。

## 安装与更新

Mac / Linux：

```sh
curl -fsSL https://github.com/ShuaiZha/media-importer/releases/latest/download/install-native.sh | sh
```

安装后执行 `media-importer update` 获取最新正式版；`media-importer uninstall` 卸载程序并保留数据。Windows 命令、PATH 设置和 Docker 切换步骤见[原生部署说明](https://github.com/ShuaiZha/media-importer/blob/v0.10.20/docs/native.md)。

发行附件包含 macOS ARM64 / AMD64、Linux ARM64 / AMD64、Windows AMD64 原生包及 SHA-256 清单；Docker 镜像为 `ghcr.io/shuaizha/media-importer:0.10.20`。

## 验证范围

Mac Apple Silicon 已完成本机安装、启停、升级、卸载与小文件 SMB 归档验收。其他平台通过构建、文件锁、服务定义和打包后的安装／卸载测试；实际相机连接及后台服务仍需相应系统的实机验证。Mac 首次后台访问外接盘时，需允许系统的可移动卷访问提示。

不修改原有相机素材或 SMB 归档。连接凭据、运行配置、数据库、缓存和本机备份不包含在源码或发行包中。
