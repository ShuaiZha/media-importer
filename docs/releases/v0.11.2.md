# v0.11.2 · 飞书交互与相机连接

[文档目录](../README.md) · [飞书设置](../feishu.md)

原生包覆盖 macOS ARM64 / AMD64、Linux ARM64 / AMD64 和 Windows AMD64；Docker 镜像为 `ghcr.io/shuaizha/media-importer:0.11.2`，支持 Linux ARM64 / AMD64。无线自动连接与预览仍限 Mac 原生版。

## 变化

- 菜单以「同步、相机、设置」分组，统一菜单事件、文字别名和卡片命令；旧入口继续可用。
- 新增「相机 → 连接相机」。单独连接不启动同步、预览或录像；已连接直接返回状态，连接中重复点击复用请求，最长等待 150 秒并更新原卡。无线自动连接仍限 Mac 原生版，USB 策略只检查直连。
- 确认相机只授权设备，不改变同步开关。取景、拍摄、模式和参数集中到相机页面；卡片保留必要确认及明确的停止操作。
- 状态卡只呈现结论、两路进度和阻塞原因；文件、速度、容量与完整归档路径进入详情。上传字节完成但尚未正式归档时显示「归档确认中」，清理结果单独表达。
- 主动开启同步立即返回进度卡，即使自动通知关闭也有回执；停止、配置保存等操作根据实际执行结果更新原卡，重复回调不会重复执行。
- 导入完成、归档完成与需处理的异常单独提醒；两路同时完成时只发送归档完成。短暂断连和自动重试更新状态，持续故障去重，恢复更新原异常卡。
- 时间继续按 UTC+8 显示，移除时区尾注与事件重复时间。新安装默认关闭连接／断开提醒，既有显式设置保留。

## 升级与保留

原生版执行 `media-importer update --version 0.11.2`；Docker 在项目目录执行 `python3 scripts/manage.py update --version 0.11.2`。先更新程序，再按[菜单表](../feishu.md#3-订阅与菜单)发布飞书应用；新增 `camera.connect`，无需新增权限或更换凭据。

配置、未完成任务、去重记录、完整缓存与已有归档保留。不改变两路队列、副本核验、原片删除条件或无线删除限制；不新增历史任务查询。

## 验证范围

发布前隔离回归共 845 项：840 项通过，5 项按平台或条件跳过。覆盖菜单与文字路由、查询无副作用、确认相机不启同步、两路统计、过期状态、正式归档与清理边界、同卡更新、重复回调，以及连接重试、超时和重启恢复。

Mac 飞书已验证菜单、表单、详情、相机页面入口和连接回执；小文件导入与结果一致性已验收。连接菜单实机验收时相机已经在线，离线重试与超时使用模拟连接验证。手机宽度下的新卡片排版待补验。
