# v1.0.2 · 照片清理与清理状态修复

本版修复清理能力判断和页面状态，不改变已有归档、配置格式或任务格式。

- HERO9 Black `HD9.01.01.72.00` 增加普通单张 JPG 的无线清理。仅处理已确认的 `GOPRnnnn.JPG`；连拍、RAW、THM 及关联关系不明确的素材继续保留。
- 自动清理与手动清理共用格式检查。在记录删除意图前检查完整关联范围，不支持的素材不会进入删除或无限重试。
- 不支持清理的素材仍正常导入与归档；归档、缓存清理完成后可正常收尾，保留必要去重依据。未知删除结果不会被当作不支持而直接丢弃。
- 删除失败保留实际原因，不再统一替换为“相机文件仍存在”。
- 没有可清理文件时只展示保留原因和关闭入口，不展示删除确认或未经核验的副本结论；核验完成后清除旧等待提示。

照片清理继续要求相机身份、源文件身份、完整关联范围及完整缓存或正式归档核验通过。默认副本条件仍为已归档，不提供格式化或清空存储卡功能。

本机验证使用专用小照片；已有相机素材和 SMB 归档不作为删除测试对象。安装与版本回收方式不变，见[原生部署](../native.md)。
