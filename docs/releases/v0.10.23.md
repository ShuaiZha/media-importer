# v0.10.23 · 缓存核验与“一次一清”

[版本列表](../README.md#版本说明) · [GitHub Release](https://github.com/ShuaiZha/media-importer/releases/tag/v0.10.23)

## 修复

- 导入流 SHA-256 与抽样证据分开核验；修改时间漂移经来源身份和抽样确认后可恢复。
- 整轮归档与必要清理完成后自动移除任务明细，保留未完成事项、去重信息、目的地依据及待发送结果。
- 收尾后状态回到等待新素材；进度更新原卡，旧记录不补发历史通知。
- 关闭原片删除后，已归档且缓存已清理的素材不再因旧删除错误阻止相机切换；结果未知的删除继续核实。
- 上传接口明确可选 `content_sha256`，旧缓存保持可用。

## 升级

原生执行 `media-importer update`；Docker 在项目目录执行 `python3 scripts/manage.py update`，Windows 使用 `py -3`。

提供五平台原生包与 `ghcr.io/shuaizha/media-importer:0.10.23` 双架构镜像。JSON 4 / SQLite 5 不变，无需重建任务；配置、未完成任务、完整缓存和已有归档保留。收尾只清除满足条件的本机任务明细。

## 验证

小文件回归覆盖缓存核验、时间漂移、旧记录迁移、去重、通知重试、相机切换和上传接口。Mac 测试 436 项通过，5 项 Windows 专用测试跳过；五平台构建及隔离维护测试由 CI 完成。另验证正式包安装、v0.10.22 → v0.10.23 更新和双架构镜像。

完整安装与维护见[原生 CLI](../native.md)和[Docker Compose](../deployment.md)。
