# v0.10.23 · 缓存核验修复与“一次一清”恢复

[版本列表](https://github.com/ShuaiZha/media-importer/blob/v0.10.23/docs/README.md#版本说明) · [GitHub Release](https://github.com/ShuaiZha/media-importer/releases/tag/v0.10.23)

恢复完成后自动收尾，修复缓存核验、完成通知与相机切换。提供 macOS ARM64 / AMD64、Linux ARM64 / AMD64、Windows AMD64 原生安装包，以及 `ghcr.io/shuaizha/media-importer:0.10.23` 双架构镜像。

## 修复

- 统一缓存核验口径：新增的导入流 SHA-256 不再被误当作抽样证据。修改时间漂移经原片身份及抽样核验后可恢复，并保留原校验值。
- 恢复“一次一清”：整轮归档与必要清理完成后，移除文件、素材组及批次明细；保留未完成事项、必要去重索引、目的地身份依据和待发送结果。
- 收尾后状态回到等待新素材，进度卡继续更新同一条消息。旧完成记录自动迁移，不重复补发完成通知；已冻结的通知保留发送重试与消息关联。
- 关闭原片删除后，已完成归档和缓存清理的素材不会被旧删除错误卡住相机切换。删除结果尚未确认时仍保留任务等待核实。
- 上传适配器接口明确可选的 `content_sha256`，与实际调用一致；没有该字段的旧缓存继续可用。

## 保留的行为

导入和上传继续并行；完整缓存不因收尾被丢弃，已有归档不修改。保留流式上传校验、单文件 SMB 连接复用、同一相机重启后的身份复核，以及飞书中的素材范围、预览归档和自动通知开关。连接及凭据仍只在 `.env`，限速与缓存额度在 JSON 中配置。

## 升级与验证

JSON 4 / SQLite 5 格式不变。更新前保存配置与 SQLite 一致快照，保留未完成任务和完整缓存；无需重新初始化。收尾只删除符合完成条件的本机任务明细，不删除相机或远端文件。

原生版执行 `media-importer update`；Docker 版在项目目录执行 `python3 scripts/manage.py update`（Windows 使用 `py -3`）。两者均通过正式发布的清单获取安装包或镜像；拉取源码不会替换已经运行的程序。新安装和详细维护步骤见[原生 CLI](https://github.com/ShuaiZha/media-importer/blob/v0.10.23/docs/native.md)与[Docker Compose](https://github.com/ShuaiZha/media-importer/blob/v0.10.23/docs/deployment.md)。

小文件回归覆盖缓存核验、时间漂移恢复、旧记录迁移、去重、消息更新与重试、相机切换和上传接口。Mac 本地测试共 441 项：436 项通过，5 项 Windows 专用测试跳过；另已验证原生包维护流程及从 v0.10.22 到 v0.10.23 的隔离升级。Windows / Linux 构建和测试以对应 CI 结果为准。
