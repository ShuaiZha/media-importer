# v0.11.5 · 源码改进记录

[文档目录](../README.md) · [架构](../architecture.md)

此版本未单独发布安装包或镜像，改动已包含在 [v0.11.7](v0.11.7.md) 正式版中。

## 数据库与查询

- 建表、迁移及旧任务摘要补齐集中到启动、安装和恢复等明确入口。
- 普通连接只检查已有数据库，不创建缺失数据库，不重复执行迁移。
- 相机页面状态、结果及媒体授权查询使用只读连接，不唤醒传输。

## 完成结果与通知

- 文件状态与完成摘要在同一事务中保存，正式归档与清理结果分别记录。
- 通知读取已保存的结果，不再扫描文件明细推断完成。
- 收尾时原子保存待发结果并清理已完成任务；通知失败单独重试，不重新传输。

配置格式、任务身份、归档路径、完整缓存和副本保护规则不变，不新增历史查询。升级无需清空数据库；源盘不可用或数据库缺失时先恢复原目录，不创建替代数据。

## 验证

隔离测试覆盖只读查询、缺失数据库、写锁并发、旧记录保留、结果事务回滚、收尾和发送重试。另用两份小 MP4 验证 T7 导入、SMB 归档、缓存清理及收尾后通知重试；未使用真实相机原片进行删除测试。
