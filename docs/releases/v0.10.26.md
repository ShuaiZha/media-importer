# v0.10.26 · 相机操作与选择上传

[版本列表](../README.md#版本说明)

提供 macOS ARM64 / AMD64、Linux ARM64 / AMD64、Windows AMD64 原生安装包，以及 Linux ARM64 / AMD64 Docker 镜像。使用 `media-importer update --version 0.10.26` 或 `python3 scripts/manage.py update --version 0.10.26` 更新现有部署。

## 主要变化

- **相机状态**：显示身份、电量、充电、温度告警、存储卡状态与实际文件数量，附观测时间；没有读取到的字段显示未知。
- **选择上传**：每个 MP4 是独立选项，只显示文件名和自身大小，正文不重复列清单。支持分页多选，确认页展示实际归档文件、数量和总大小。
- **独立任务**：停止全量同步后执行选定任务，复用并行导入与上传；停止、继续和重启保持确认范围。未选任务和缓存保留，已有归档通过大小与身份核验后不重复上传。
- **原片清理**：默认选择已归档素材，也可选择已完整导入的素材。先预览再确认，执行前复核关联完整性与副本；结果区分已删除、原片已不存在、保留和待核验。断线或重启后只复查不确定结果，不继续执行未完成的删除。
- **卡片回执**：两路进度与停止结果更新到原卡片；空选择、过期预览、重复点击和发送失败均保留明确反馈。
- **安装验收**：隔离安装测试不再依赖 CI 运行器上的 Docker 服务，避免 Windows Docker 探测超时误报；正式程序仍检查任务与缓存是否被 Docker 占用。

选定上传**固定保留相机原片**，不修改全量同步与自动删除开关。LRV、THM 按现有预览文件设置处理；清理条件不会因某个 MP4 被单独选中而放宽。配置、未完成任务、完整缓存和已有归档保持不变，原开关值不重置。

## 升级后

按[飞书菜单表](../feishu.md#3-订阅与菜单)新增「状态 → 相机状态」「同步 → 选择素材」「同步 → 清理原片」，然后发布应用。沿用现有权限、凭据和事件订阅；更新程序不会自动修改飞书后台菜单。

JSON 4 / SQLite 5 保持不变。数据库新增短期相机操作和选定任务记录，仍按“一次一清”收尾；未完成任务与待核验删除依据保留。使用步骤见[选择素材导入](../feishu.md#选择素材导入)与[相机操作](../feishu.md#相机操作)。

## 验证范围

609 项自动测试：604 项通过，5 项 Windows 专项在 macOS 跳过。小文件隔离测试覆盖单文件选择、关联预览策略、未选任务保留、并行传输、归档核验、停止恢复，以及删除前完整性、源身份变化、响应丢失和清理竞态。

实际飞书客户端已验证独立 MP4 选项、预览、空选择提示和取消交互。未删除现有相机原片；本次手动清理的实机删除行为仍待单独验收，不能以模拟测试替代。
