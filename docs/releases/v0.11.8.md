# v0.11.8 · 素材状态与选择清理

源码阶段记录，未单独发布安装包或镜像；改动整合在 [v1.0.0](v1.0.0.md)。下文验收范围为该阶段记录，当前范围见[兼容性](../compatibility.md)。

- 相机素材页显示当前目的地的文件备份状态，支持全部、待备份、已归档筛选。
- 勾选文件后可核验并清理原片，默认要求正式归档存在且大小、身份匹配。确认页展示具体文件、关联预览、预计释放空间及保留原因。
- 可改为清理已完整导入的文件；未归档时缓存可能是唯一副本，确认前明确提示。复用现有清理队列及缓存保护，不改变自动删除开关。
- 不扩大所选范围。其他主文件、关联不明、源身份变化或副本不足时保留；删除结果未知时只复查，不重发删除。
- HERO9 `HD9.01.01.72.00` 的 MP4 与关联 LRV 开放无线清理；其他型号、固件及照片、THM 无线删除仍未开放。

保留现有配置、未完成任务、完整缓存、去重依据及已有归档。无新配置项、菜单权限或数据库迁移。素材页沿用 Mac 原生入口；关闭旧窗口，从飞书重新打开即可使用。

验证包括隔离小文件的状态、筛选、取消、清理范围、重复确认、响应丢失与副本保护，以及专用新录制文件的无线导入、SMB 归档和原片清理；其他既有原片不参与删除测试。真实手机端待补验，窄屏布局通过隔离页面检查。
