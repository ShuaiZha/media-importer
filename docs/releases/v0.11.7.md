# v0.11.7 · 相机素材页选择备份

[文档目录](../README.md) · [相机页面](../feishu.md#相机页面)

- 相机素材页支持在缩略图或回放窗口勾选独立文件，确认实际归档范围与目的地后提交备份。
- 复用现有选择任务、并行队列、进度事实和副本保护；提交后释放浏览占用，支持查看进度、停止及继续本次任务。
- 单次备份固定保留原片，不改变全量备份或自动删除设置；重复确认、过期清单及配置变化沿用身份与任务核验。

## 同时收录的改进

相较于上一正式版 v0.11.2，本次还包含：

- HERO9 有声 RTMP 直播，可在飞书配置 Wi-Fi，自动识别本机接收地址；保留原有低延迟预览。
- 相机调度、状态与飞书入口统一，菜单为「备份、相机、设置」，保留旧事件和文字命令。
- 数据库初始化与日常查询分离，完成结果与通知发送分离；通知重试不重复传输。
- 任务收尾、缓存保护与状态刷新优化，继续保留两路并行、副本保护和“一次一清”。

## 安装与更新

原生包覆盖 macOS ARM64 / AMD64、Linux ARM64 / AMD64、Windows AMD64；Docker 镜像为 `ghcr.io/shuaizha/media-importer:0.11.7`，支持 Linux ARM64 / AMD64。无线连接、拍摄、素材页面与画面功能仍限 Mac 原生版；Docker 保留飞书文件选择入口。

原生版执行 `media-importer update --version 0.11.7`；Docker 在项目目录执行 `python3 scripts/manage.py update --version 0.11.7`。首次安装见[原生 CLI](../native.md)或[Docker Compose](../deployment.md)。

升级保留配置、未完成任务、完整缓存与已有归档。素材页选择备份无新增配置字段、飞书权限、端口或数据库迁移。先更新程序，再按[菜单表](../feishu.md#3-订阅与菜单)更新并发布飞书菜单；关闭旧相机窗口，从飞书重新打开新版页面。
