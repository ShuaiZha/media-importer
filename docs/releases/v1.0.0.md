# v1.0.0 · 首个稳定版本

相机素材备份、飞书控制和相机页面形成完整使用流程。本版整合 v0.11.8、v0.11.9 源码阶段的素材状态、选择清理、交互优化及无线读取恢复，不再扩展新功能。

## 本版内容

- 相机素材先完整导入本地，再由独立队列并行归档到 SMB。离线缓存、失败恢复、平铺命名和重名保护继续沿用。
- 飞书以「备份、相机、设置」组织入口；当前状态、两路进度、最近结果与清理事实分别表达，查询不会开启传输或拍摄。
- Mac 相机素材页支持缩略图、回放、单文件选择备份、备份状态和简单筛选。跨页及跨筛选保留选择，并标明筛选外已选文件。
- 选择清理默认只允许已归档素材；确认前核验源身份、实际副本及关联范围，分别展示原片、辅助文件和预计释放空间。取消与结果未知不当作删除成功。
- 拍摄页面与播放器适配桌面及手机，常用与高级参数分层。只读状态和参数查询遇到短暂无线故障时，释放旧连接后最多重试一次；权限拒绝、身份不符和拍摄写入不自动重发。
- 源码采用 MIT 许可，原生包与 Docker 镜像包含项目许可，第三方组件保留各自声明。

## 支持范围

主要实机验证组合为 **Mac Apple Silicon、HERO9 Black（HD9.01.01.72.00）、SMB、本人飞书单聊**，覆盖 USB / 无线备份及 MP4/LRV 副本核验后的清理。

Mac 原生版提供无线连接、拍摄控制、相机页面与低延迟预览；Mac 和 iPhone 飞书已验证素材页与回放，iPhone 经 Tailscale 的 WebRTC 预览已有实测记录。有声 RTMP 直播保持实验功能，停止后的无线恢复与客户端支持以[兼容性表](../compatibility.md)为准。

提供 macOS ARM64 / AMD64、Linux ARM64 / AMD64、Windows AMD64 原生包，以及 Linux ARM64 / AMD64 Docker 镜像。跨平台构建及隔离安装测试不等于全部硬件链路完成实机验证。其他 GoPro 型号允许确认后尝试导入，未验证的删除保持禁用；其他品牌尚未接入。

## 升级

- 原生：`media-importer update`，或指定 `--version 1.0.0`。
- Docker：在项目目录执行 `python3 scripts/manage.py update --version 1.0.0`，Windows 使用 `py -3`。
- 更新保留凭据、设置、未完成任务、完整缓存与去重依据；不移动或删除已有归档。v0.11.7 至本版没有新增配置或数据库迁移。
- 新安装的备份、自动删除与自动通知默认关闭；升级保留原开关值。首次验证保留原片并使用小文件。
- 按[菜单表](../feishu.md#3-订阅与菜单)发布新增的「相机素材」入口及菜单名称；原有事件和文字命令仍兼容，无需更换飞书凭据或权限。
- macOS 更换程序后可能再次要求访问缓存盘或配置目录；需要本人允许。程序尚未进行 Developer ID 公证。相机页面入口一小时后失效，重新从飞书获取。

## 副本保护与已知边界

每个实例只处理一台来源相机和一个 SMB 目的地，同一份任务与缓存只能运行一个实例。备份与相机画面、拍摄使用统一占用规则；完整缓存上传不占用相机。

自动删除仍为独立开关。开启后，整组素材完整导入并通过核验即可清理原片，此时缓存可能是唯一副本。归档完成以大小核对、禁止覆盖的正式改名和记录持久化为准，不全量读回远端视频，也不新增视频 SHA-256 比对。

中断文件从头传输，完整缓存保留；相机和缓存清理不会删除 SMB 正式归档。详细使用和恢复方式见[文档目录](../README.md)。
