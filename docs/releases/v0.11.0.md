# v0.11.0 · 双链路、拍摄控制与预览（开发版）

[文档目录](../README.md) · [兼容性](../compatibility.md)

本版本已完成下述 Mac 与 HERO9 本地验收，尚未发布到在线安装和镜像渠道。正式安装命令仍获取 v0.10.26。

## 变化

- Mac 原生版自动选择 USB / Wi-Fi，USB 优先；保留单独的 USB 地址提示。
- 已确认设备按完整身份识别，重连不再重复确认；陌生设备仍须确认。
- 修复 HERO9 重启后媒体接口创建时间漂移导致的重复归档：扫描与下载核验使用 MP4 文件头时间，关联预览文件保持同一身份；既有任务 ID、缓存及去重记录保留。
- 蓝牙连接、热点启动与系统 Wi-Fi 连接有超时和重试，不新增 App。
- 飞书可在相机离线时开启同步；已确认相机自动重连并备份，陌生相机仍需确认。停止同步取消自动连接尝试。
- 运行状态与进度卡统一突出连接、两路进度和异常；蓝牙识别成功不会被误报为媒体连接就绪，持续连接失败只提醒一次并更新恢复结果。
- 飞书「拍摄控制」支持实际状态、录像启停、拍照、延时摄影和 HiLight；录像时长与结果更新同一张卡片。
- 动态读取相机预设、分辨率、帧率、视角、防抖、录像时长及延时间隔。单项修改前重新核验可用值与预设，修改后读回；定长录像由相机执行。
- 增加相机页面，将实时取景、拍摄控制和参数放在同页；素材页逐个展示 MP4、照片缩略图，支持视频按需回放。沿用本机 / Tailscale 入口，旧观看链接仍只读；不增加服务、依赖或磁盘视频缓存。
- 常用参数增加白平衡、ISO、快门、曝光补偿、色彩、锐度、码率、照片输出，按当前相机定义和能力开放。浏览与实时预览互斥；浏览占用自动到期，完整缓存上传不受影响。
- 预览转拍摄先确认停流；拍摄后可确认导入本次新增文件，沿用双队列和原片保护，不改变全量同步设置。仅保留最近拍摄范围，不增加历史查询。
- 拍摄中断当前未完成导入，完整缓存与 SMB 上传继续；快门命令不自动重发。
- 飞书采用「同步、相机、设置」菜单与稳定事件标识；只读状态不抢占导入，停止录像优先，预览结束确认后才开始录像。
- Mac 原生包内置 go2rtc，通过「相机 → 实时预览」在飞书打开画面，可经 Tailscale 远程观看 HERO9 无线画面；无需另装 FFmpeg。预览独立启停，不改变同步与删除设置。
- 预览期间暂停相机导入与清理，完整缓存仍可上传；不因无人观看而结束，后台退出后回收组件，重启不自动开启画面。
- 优先采用 WebRTC 降低播放缓冲；连接未成功时自动回退 MPEG-TS HLS / MSE，保留 Apple 播放兼容。WebRTC 视频端口仅绑定本机或 Tailscale 私有地址；页面、协商与兼容视频继续使用 HTTPS 入口。不新增转码、外部 STUN/TURN 或手机摄像头权限。停止预览撤销链接并回收组件。
- 远程预览地址和只读连接检查接入飞书；可读取本机 Tailscale 入口，检查并保存后使用。配置升级为 version 5，相机、SMB 和预览业务参数只从 JSON 读取，SMB 密码采用本机文件引用；旧环境字段一次性迁移。

## 保留与边界

配置、未完成任务、完整缓存和归档规则保留；既有显式 USB 策略不自动改变。无线原片删除强制关闭，USB 删除仍沿用机型验证条件。

无线自动连接要求 Mac 有独立有线上网链路。Linux、Windows、Docker 保留 USB；家庭 Wi-Fi 恢复和多设备调度不包含在本版；远程客户端兼容性单独验收。

## 本地验收

隔离测试共 825 项：820 项通过、5 项按条件跳过，覆盖身份与会话切换、离线开启后的自动重连、连接中停止、故障通知去重、拍摄幂等、重启只读恢复、预览与导入互斥及完整缓存继续上传，以及 HTTPS/HLS 路由限制、停止后的会话撤销、同步关闭时的停止核验重连。包含接收型 WebRTC 协商、私有地址绑定、客户端回退与恢复，以及动态参数、修改后读回、预设变化拒绝写入、同步关闭时的拍摄清单核验、本次拍摄小文件导入等回归。相机页面新增本人入口、令牌失效、同源控制、分段回放、素材身份与浏览占用保护测试。创建时间漂移回归：保留既有去重记录、待处理任务和完整缓存，同名同大小的新素材仍单独归档。

- 低延迟预览：Mac 飞书、浏览器与 Safari 验证 WebRTC 播放；用户确认 iPhone 飞书经移动网络与 Tailscale 连续播放，观察延迟由 2–4 秒降至 1 秒以内。未以接收端缓冲数据冒充端到端延迟。
- 预览配置：真实飞书表单验证读取入口、连接检查、保存回执，以及仅本机与 Tailscale 入口切换后的即时生效。迁移前后有效配置、任务与去重记录、缓存一致；两个 128 KiB 模拟源文件通过 T7 和独立 SMB 目录完成归档、大小与身份核验及缓存清理，相机未执行写操作。
- HERO9 实机：自动重试连接相机热点并核对完整身份，Mac 仍通过有线网络访问 SMB；飞书卡片完成照片 / 视频模式切换、单张拍照、开始及停止录像。
- 拍摄扩展：HERO9 实际返回当前可用预设和参数；修改帧率、录像时长并读回。15 秒定长录像由相机自动结束，录像中 HiLight 数量增加；照片和短延时均生成文件，测试后恢复原预设和修改过的参数，原有素材保留。
- 统一相机页面：Mac 飞书经 Tailscale HTTPS 打开，读取当前视频模式的 13 项参数，白平衡修改后读回并恢复。真实 MP4 与照片分别展示缩略图；2.6 MiB 小视频使用约 246 KiB 的关联预览副本成功回放，隔离浏览器验证 64 KiB 分块读取并播放到结尾。页面内 WebRTC 取景、开始与停止录像、结束预览均通过实机验证。浏览不创建导入任务、不写视频缓存；原有 15 个相机文件核验未变，测试新录像及附属文件保留。该新页面尚未单独在 iPhone 飞书验收。
- 飞书拍摄交互：真实卡片验证参数表单、照片模式规格、预览结束后拍照，以及同卡回执不被旧预览更新覆盖。同步关闭时，一张约 5.46 MiB 的新照片经确认完成 T7 导入与 SMB 归档，两路均显示 1/1、100%；大小和文件身份一致，对应缓存已清理，原片保留。蓝牙超时时未重发快门，复核后重新操作成功。
- 真实素材：一个 8.1 MiB 视频和一张 5.8 MiB 照片通过 Wi-Fi 导入与 SMB 上传；两路有实际并行区间，远端大小和身份一致，缓存由程序清理。测试仅移除独立测试目录内的产物，原片保留。
- 协议兼容：修复预设枚举、普通拍摄预设选择、热点有限重试与媒体离线时的蓝牙停止录像；修复 HERO9 拍照后错误返回新视频大小的情况，仅在媒体清单、实际文件和视频头部身份一致时接受补读结果。
- 重启去重：实机重启后两段视频接口时间偏移 32 秒，修复后全部 7 个文件的身份与重启前一致，既有 4 条去重记录继续命中。一个 8.1 MiB 视频通过独立 T7/SMB 目录完成归档；再模拟接口时间变化并重新打开任务库，未再次下载或生成新归档，原片与既有归档保留。
- 最新原生包：后台与飞书连接健康；实际从飞书选择一个 8.1 MiB MP4，完成卡显示两路均为 1/1、100%。核对 SMB 大小与身份一致、缓存已清理、任务明细已收尾，既有归档与全部相机原片保留。
- 集成预览：Mac 包内置 go2rtc v1.9.14；Mac 飞书通过私有 HTTPS/MSE 出画，Mac Safari 与 iPhone 飞书通过 MPEG-TS HLS 出画。iPhone 使用移动网络与 Tailscale，实际画面连续播放超过两分钟。无人观看 190 秒后同一会话仍保持开启；飞书结束预览后，相机预览标志归零，旧链接返回 410，组件无残留。并行上传与相机操作互斥使用小文件隔离回归验证；配置、任务和缓存保留，7 个相机源文件未删除。

备份重连实测通过断开 Mac 的相机 Wi-Fi 再自动连接完成；另已验证相机断电开机后，由预览请求自动重连并出画，开机后的自动备份仍待专项验收。其他机型、其他平台的无线能力以及长期稳定性尚未验收；无线原片删除仍强制关闭。

测试保留相机原片；同步、原片删除和预览关闭。当前构建不作为正式发布。
