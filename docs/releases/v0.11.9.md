# v0.11.9 · 飞书与相机页面交互重整

源码阶段记录，未单独发布安装包或镜像；改动整合在 [v1.0.0](v1.0.0.md)。

- 菜单区分「开启自动备份」与「选择文件备份」。相机提供「画面与拍摄」「相机素材」「批量清理原片」，旧文字和事件入口保持可用；页面不可用时仍可使用选择卡。
- 当前开关、当前任务与最近结果分开显示。两路进度继续依据持久化事实；归档确认与缓存清理不会被提前算作完成。原片与辅助文件分别计数，异常与取消使用不同状态。
- 素材、连接设置统一保存；请求参数、SMB 端口与认证域放入高级项，通知间隔使用分钟。字段校验指出具体问题，启用自动删除、切换归档位置仍需确认。
- 拍摄页缩小未开启画面的占位，首屏保留主要控制，常用与高级参数分开。播放器收起兼容选项，结束后隐藏无效操作。
- 素材页优先显示文件，完成结果折叠；有选择时显示固定操作栏，跨筛选保留选择并标注隐藏选择。确认页继续列完整范围与副本条件。
- 增加页签键盘操作、参数控件名称，改善文字对比度，避免未变化的进度反复重建和播报。
- 参数与状态读取遇到短暂蓝牙或 Wi-Fi 故障时，释放旧蓝牙连接后自动重试一次，总等待仍受限；权限拒绝、身份不符或命令拒绝不重试。错误提示区分连接、通知初始化、命令响应和 Wi-Fi 请求；录像、拍照及参数修改不自动重发。

配置、任务、完整缓存、已归档文件与副本保护不变，无数据迁移。更新本机后须按[飞书菜单表](../feishu.md#3-订阅与菜单)发布菜单。验证使用隔离小文件，不对现有相机原片执行删除。
