# v1.0.3 · 副本保护与扫描故障隔离

本版修复安全审查确认的三项问题，不新增配置字段，不改变数据库格式；配置、任务、完整缓存和既有归档保留。

- 缓存清理及重试前重新核对 SMB 正式文件大小和身份。副本缺失、变化或无法核验时保留完整缓存，显示归档待核验；其他文件继续上传，不覆盖或重复上传既有归档。
- 单个文件元数据损坏不再阻断正常文件的导入、选择备份和浏览。不完整清单保留去重与源文件记录，暂停原片清理和全量完成通知；异常路径及原因在素材页和备份详情显示。连接失败和相机忙碌仍按整体故障处理。
- 手动清理预览仅保护当前素材组，SMB 请求期间不持有全局缓存锁；确认删除时仍重新核验完整副本。

本版包含 [v1.0.2](v1.0.2.md) 的照片清理修复。安装和更新方式不变，见[原生部署](../native.md)。

## 验证

- 完整隔离回归 1004 项：997 项通过，7 项按平台条件跳过；覆盖远端丢失、同大小替换、断网、损坏 MP4、扫描恢复、完成提醒和清理并发。
- 使用真实 SMB 与隔离的 T7 缓存验证两个 32 字节文件：正常归档后清理缓存；远端测试文件丢失后保留完整缓存并阻止完成判定。仅清理本次创建且身份匹配的远端文件，不访问相机原片。
- 原生安装包通过隔离安装、更新、保留数据卸载和彻底卸载测试；不对实际安装执行卸载。
