# v0.11.6 · 源码改进记录

[文档目录](../README.md) · [业务流程](../workflows.md)

- 统一相机操作准入与占用规则，停止录像优先；导入等待相机时完整缓存仍可归档。
- 连接、当前用途、拍摄观测和画面状态共用只读事实；直播不因素材接口不可达而显示离线。
- 飞书入口统一为“备份、相机、设置”；旧事件和文字命令继续可用。
- 相机状态直接读取快照，设备详情保留主动核验；相机页面复用同一状态与操作限制。
